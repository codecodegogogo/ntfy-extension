# ntfy-extension（汉化增强版）

一个用于发送和接收 ntfy 通知的浏览器扩展，基于
[TheDuffman85/send_to_ntfy_extension](https://github.com/TheDuffman85/send_to_ntfy_extension)
修改，遵循 MIT 许可证。

当前版本：**3.3.0**

## 本版本完成的修改

- **界面汉化**：弹窗、设置页、右键菜单、桌面通知、文件选择器、表情分类和错误提示均已翻译为中文。
- **设置页重组**：分为「发送」「接收与订阅」「外观」三个区块；「发送」和「接收与订阅」各带一个开关，默认关闭，关闭时折叠且不启用对应功能。
- **多个发送服务器**：发送支持添加任意多个服务器，每个服务器有自己的地址、发送主题和访问凭据；发送时按所选主题自动使用对应服务器。
- **多个订阅**：接收支持添加任意多个订阅，每个订阅可以有自己的服务器和多个主题。
- **主题列表可隐藏**：弹窗标题右侧的列表按钮可以收起主题列表，收起后整个列表隐藏、消息区域占满宽度，再点同一按钮随时展开；当前选中主题的消息仍然显示；弹窗内不显示滚动条。
- **手动拉取**：标题行铃铛后面的刷新按钮会立刻向服务器重新拉取一次所有订阅主题的消息（服务器缓存中的全部消息），不弹桌面通知，完成后提示拉到几条新消息。
- **主题备注**：双击侧边栏中的主题可以设置备注，备注会代替主题名显示；不同订阅里的同名主题分别显示，不再合并。
- **WebDAV 备份与还原**：设置页新增「备份与还原」，可把发送服务器、订阅、凭据和显示设置备份到 WebDAV 服务器，或从服务器、本地文件还原；备份可用 AES-GCM 加密。
- **独立服务器**：发送和每个订阅可以连接不同的 ntfy 服务器；订阅的服务器留空时使用第一个发送服务器，主题留空时使用同一服务器上的发送主题。
- **按服务器凭据**：每个发送服务器和每个订阅卡片里都有自己的「访问凭据」，各服务器的令牌互不影响；订阅服务器与某个发送服务器相同时，凭据留空会复用那个发送服务器的凭据。
- **403 提示**：服务器拒绝读取主题时，设置页和消息列表会提示在对应订阅里填写访问凭据。
- **多连接接收**：后台为每个订阅服务器分别建立 WebSocket 连接，轮询、消息历史和未读计数按服务器区分，同名主题不会串消息。
- **权限提示**：某个订阅服务器被浏览器拦截时，会在对应订阅卡片中单独显示「允许访问此服务器」按钮。
- **旧配置迁移**：旧版的单个订阅服务器/主题会自动迁移为第一个订阅；已配置发送的老用户升级后发送开关自动开启。
- **保留原功能**：右键发送、附件与 ZIP、优先级、标签与表情、Markdown、桌面通知、主题和弹窗尺寸等。

## 安装

- **Chrome / Edge**：解压 `build/send-to-ntfy-zh-chrome-v3.3.0.zip` 得到 `ntfy-extension-chrome-v3.3.0` 文件夹，在扩展页开启开发者模式，选择「加载已解压的扩展程序」并选中该文件夹。zip 和 crx 都不能直接拖进扩展页安装。
- **Firefox**：在 `about:debugging#/runtime/this-firefox` 中临时载入 `build/send-to-ntfy-zh-firefox-v3.3.0.xpi`。

详细配置和使用方法见 [使用说明.md](使用说明.md)，本次版本的改动明细见 [更新说明.md](更新说明.md)。

## 构建

```bash
./build.sh          # Chrome + Firefox
./build.sh chrome
./build.sh firefox
```

需要 `node`；打包用 `zip`,没有时自动回退到 PowerShell 的压缩组件。构建产物在 `build/`。Chrome 的 zip 里套了一层 `ntfy-extension-chrome-v<版本>` 文件夹,解压后直接把这一层文件夹加载为「已解压的扩展程序」。
